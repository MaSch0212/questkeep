Richer game details (optional)

Questkeep gets most details from your stores. Two free services add more; both need a key from your own free account, stored only in your system's keyring.

IGDB (via Twitch)Recommended

Time to beat, wiki and social links, series, age ratings, game modes, themes, and details for games your stores know little about.

  1. Sign in at dev.twitch.tv/console (any Twitch account; turn on two-factor authentication if asked).
  2. Register an application: any name, OAuth redirect http://localhost, category "Application Integration", client type "Confidential".
  3. Copy the Client ID, create a New Secret, and paste both here.

Continue without IGDB?

Without an IGDB key these stay empty:
  • Time to beat
  • Website, wiki and social links (store links still work)
  • Series, age ratings, game modes, themes, perspectives, and filters on them
  • Details for games from stores without metadata (Ubisoft, EA, Battle.net, manually added)

You can add the key any time in Settings → Metadata, then use "Refresh metadata for all games".
