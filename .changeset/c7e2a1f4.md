Store plugins can now do what Questkeep's own stores do: find where a launcher is installed on their own (reading files and the registry), read other programs' databases, keep sign-in tokens in the system keyring, offer account sign-in, and name the launcher programs Questkeep may close after a game. The install dialog lists everything a plugin can reach, including every web address and sign-in domain, and warns about plugins that did not come from the plugin registry. Updates that ask for more access are never installed by "Update all". A plugin that returned a launcher to close after a game must now name its programs in its plugin.json.
