Saved library views: the sidebar now lists your own views (filters, sort order and layout), grouped in sections you can rename, reorder and edit. Unsaved changes to a view are marked and can be saved, saved as a new view or reset. The title bar gets a Questkeep menu, Add game, Open launcher and Sync buttons (the sync popup lists every store with its last sync) and a "Find a game…" command bar (Ctrl+K) that opens or starts any game. The list and details views show game icons in shorter rows.
