Game scripts: run programs or scripts before a game starts, after it closes, or as actions from the game's page and right-click menu. Scripts can be global, limited to games matching a filter, or belong to one game, in an order you arrange. Write them in Questkeep for PowerShell 7, Windows PowerShell, Bash, the Command Prompt or Python (whichever is installed), link or import script files, and use every detail of the game as environment variables or `{Placeholders}`. **Run now…** in the script dialog shows the output and exit code of a test run.
